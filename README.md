# Cisco Packet Tracer Projects

This repository contains Cisco Packet Tracer activities and network simulation files for learning and practicing networking concepts.

## Contents

- **1.1.6-packet-tracer-tutored-activitys-logical-and-physical-mode-exploration.pksz** - Tutored activity exploring logical and physical modes in Packet Tracer

## About Cisco Packet Tracer

Cisco Packet Tracer is a powerful network simulation tool that allows students and network professionals to:

- Design and build virtual networks
- Configure network devices (routers, switches, etc.)
- Simulate network protocols and services
- Practice troubleshooting network issues
- Understand network topology concepts

## File Format

`.pksz` files are Cisco Packet Tracer activity files that contain:

- Network topology
- Device configurations
- Activity instructions
- Assessment criteria

## Getting Started

### Prerequisites

- Cisco Packet Tracer software installed
- Basic understanding of networking concepts

### Opening Files

1. Launch Cisco Packet Tracer
2. Go to **File** → **Open**
3. Select the `.pksz` file you want to work with
4. Follow the activity instructions provided within the file

## Learning Objectives

These activities help you learn:

- Network topology design
- Device configuration
- Protocol implementation
- Troubleshooting techniques
- Logical vs Physical network views
